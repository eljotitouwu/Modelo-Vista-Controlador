# Sorteo de equipos para una liga profesional

Tarea Unidad 3 - Programación Orientada a Objetos (UPS).

Estructura MVC:
- `src/modelo`: Equipo, Partido, Etapa, Sorteo (recursivo), Torneo (Serializable), excepciones propias.
- `src/vista`: VistaConsola (solo entrada/salida).
- `src/controlador`: ControladorTorneo (mediación y persistencia).
- `src/Main.java`: punto de entrada.

Ejecución: abrir la carpeta en VS Code (con "Extension Pack for Java") y ejecutar `Main.java`.
